Case Study

Alumni Tracer System

A Node.js and MariaDB platform for recording alumni information, employment status, and graduate tracking reports.

Overview

The project solves the challenge of scattered alumni data by creating a centralized database and reporting workflow for graduate tracking.

My Contributions

Responsible for backend routes, authentication, database schema, alumni profile management, and reporting workflows.

Features

Authentication, alumni profiles, survey forms, admin dashboard, data filters, employment reports, and export-ready summaries.

Technologies

Node.js, Express.js, MariaDB, JavaScript, SQL, Tailwind CSS, Postman, and GitHub.
