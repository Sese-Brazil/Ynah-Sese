BonBon Online Cake & Pastry Shop

A Laravel e-commerce system for managing online cake and pastry orders, product catalogues, customer transactions, and admin operations.

Overview

BonBon Online Cake & Pastry Shop is a full-stack e-commerce platform designed to streamline online cake ordering through an intuitive shopping experience, secure payment processing, product customization, and administrative management. The system enables customers to browse products, customize cakes, place orders, and track purchases while providing administrators with comprehensive tools for inventory, order, customer, and business management.

My Contributions

As a Full-Stack Developer, I was responsible for developing and implementing the following modules and features:

  • Designed and developed the core user interface foundation used throughout the application.
  • Implemented AI-powered chat support to assist customers with inquiries and shopping assistance.
  • Developed the live chat support feature for real-time communication between customers and administrators.
  • Built the user authentication system, including login and registration functionality.
  • Integrated Google OAuth for secure third-party authentication.
  • Implemented the forgot password and password reset backend functionality.
  • Developed the invoice printing feature for completed customer orders.
  • Implemented report export functionality for administrative records.
  • Built the user notification system for important account and order updates.
  • Developed the integrated code reviewer module to support code quality and maintainability during development.

Features

  • User authentication with email and Google Sign-In
  • Product catalog with search, filtering, and categorization
  • Shopping cart and checkout workflow
  • Guest checkout and guest order tracking
  • AI-powered customer support
  • Real-time live chat support
  • 3D cake customization and cake model integration
  • Order, inventory, and product management
  • Administrative dashboard with analytics
  • Bulk product upload
  • Secure PayMongo payment integration
  • User account and notification management
  • Printable invoices and report export
  • Interactive map-based address selection
  • Responsive user interface with modern web design

Technologies

Laravel, PHP, MySQL, Tailwind CSS, JavaScript, HTML, CSS, Google OAuth, Groq API, REST API, Git/GitHub
