AURA AI

Adaptive Understanding and Retrieval for Automated Summarization is an AI-powered system for finding, understanding, and summarizing information from documents.

Overview

The project addresses the difficulty of manually searching long documents and extracting useful insights. It combines retrieval, NLP, and summarization to help users get concise answers faster.

My Contributions

Responsible for backend development, document processing workflows, retrieval logic, database design, and AI integration.

Features

Authentication, document upload, semantic search, AI chat, automated summarization, dashboard, and report generation.

Technologies

Python, NLP, information retrieval, named entity recognition, LLM integration, SQL, and Tailwind CSS.
